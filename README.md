\## Engine



Godot 4 / GDScript



\## Assignment 3 MVP



The MVP demonstrates a procedural 2.5D dungeon crawler using:



\- Grid-based movement

\- Procedural rooms and corridors

\- 3D dungeon rendering

\- Multiple room elevations

\- Ramps between elevations

\- Fog of war

\- Skeleton enemy pathfinding

\- Basic combat
